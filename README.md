# Project-ConnectaTel
Evaluar el comportamiento de los clientes de una empresa de telecomunicaciones en Latinoamérica

Análisis de clientes y patrones de consumo — ConnectaTel

Descripción del proyecto

Este proyecto tiene como objetivo analizar los datos de clientes de ConnectaTel para identificar patrones de consumo, segmentar a los usuarios y proponer oportunidades de mejora en la oferta de planes de telefonía.

A través del análisis exploratorio de datos, la limpieza de datos y la identificación de valores atípicos, se busca generar información útil para apoyar la toma de decisiones comerciales.

Objetivos

* Evaluar la calidad de los datos e identificar inconsistencias.

* Analizar la distribución de los clientes según su edad y nivel de uso.

* Identificar patrones de consumo de mensajes, llamadas y minutos.

* Detectar y evaluar valores atípicos mediante el método del rango intercuartílico (IQR).

* Formular recomendaciones comerciales basadas en los hallazgos.

Los datasets utilizados:

Usage, Users y Plans

Etapas de análisis realizadas: 

* Exploración de los datos: revisión de la estructura, las variables y las características del conjunto de datos.

* Limpieza de datos: identificación y tratamiento de valores nulos e inconsistencias.

* Análisis de valores atípicos: aplicación del método IQR para identificar consumos extremos y evaluar su conservación.

* Segmentación de clientes: agrupación según edad y nivel de uso.

* Análisis ejecutivo: interpretación de resultados y formulación de recomendaciones comerciales.

Cómo ejecutar el proyecto

Puedes consultar y ejecutar el notebook directamente desde Google Colab, sin necesidad de instalar Python ni configurar un entorno local.

1. Abre el notebook disponible en este repositorio de GitHub.

2. Haz clic en el botón Open in Colab si está disponible. Si no aparece, copia la URL del notebook y utiliza la opción de GitHub en Google Colab para abrirlo.

3. Una vez abierto en Google Colab, selecciona Entorno de ejecución → Ejecutar todas (Runtime → Run all).

4. Si el notebook requiere archivos de datos externos, asegúrate de cargarlos o configurar las rutas correspondientes antes de ejecutar las celdas.

Nota: La ejecución completa depende de que estén disponibles los archivos de datos y las dependencias necesarias para el proyecto.
